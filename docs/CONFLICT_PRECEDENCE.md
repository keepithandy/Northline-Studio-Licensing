# Conflict and Precedence Examples

These fictional examples illustrate the scope note in the [policy hub](../README.md). They are not legal opinions about real disputes.

1. **Repository code license versus hub summary.** A project repository includes Apache-2.0 for its source code while this hub summarizes the split-license model. The repository license controls that project's code because it is project-specific.
2. **Creative asset notice versus source-code license.** A PNG has an All Rights Reserved notice inside a repository whose code is Apache-2.0. The asset notice controls the PNG; the software license does not automatically license creative content.
3. **File header versus repository default.** A source file contains a valid, more specific license header that differs from the repository default. Review the file-specific notice and repository terms together; the more specific file terms govern that file where valid.
4. **Third-party font.** A project includes a font under its original SIL Open Font License. The font's original terms control the font, including required notices, regardless of Northline's own asset policy.
5. **Catalog versus project terms.** `PROJECTS.md` contains an outdated summary but the project repository has current dated terms. The project terms control; the catalog must be corrected.
6. **Missing evidence.** An audio file has no source, author, or license record. Mark it UNRESOLVED, do not distribute it as cleared material, and ask for provenance review.

When evidence is incomplete or terms appear contradictory, stop and request human review rather than assuming permission.
